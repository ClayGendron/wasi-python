## Decisions

### 1. The six `src/` pointers name the site's page

A docstring and a message may name a page of the documentation site. "Code speaks for itself" (AGENTS.md) forbids a specification, decision, memo, review, numbered question, finding or `context/` path in a code file; the site is what the project tells its users, and a pointer to it is a reader's way on, not a citation of the knowledge tree. `tests/lint/test_writing_conventions.py`'s `src/` scan (`CITATION_KINDS`) refuses `context/` and says nothing of `docs/` or the site, and the string rule (`scan.string_citation_hits`) treats a path or a URL as data. A pointer names the page by its title and, where a reader may hold only the wheel, by its URL: the wheel carries no `docs/` folder, so `docs/reference/python-api.md` means nothing to someone reading `help(wasi_python)`. A message (text a user reads in a traceback) gives the URL; a module docstring gives it once; an attribute's or a function's docstring names the page and its section in words, since its module's docstring has the URL. The site's address is `https://claygendron.github.io/wasi-python/` (`mkdocs.yml:6`, the README's links).

### 2. The command's six options carry their `help=`, and `DESCRIBED` goes

`cli.py` gives `--env`, `--deadline-s`, `--memory-bytes`, `--output-bytes`, `--fuel` and `--no-snapshot` a `help=` whose text is `DESCRIBED`'s sentence for that option, word for word (`cli_doc.py:29-38`), so `wasi-python run --help` describes every option and `docs/reference/cli.md`'s block renders byte for byte as it does today (`uv run python tests/harness/cli_doc.py --check` exits 0 with no rewrite). `DESCRIBED` and `render`'s `described` parameter are deleted from `cli_doc.py`; the description is the option's `help=`, and `render` raises `ValueError` naming each option that has none ("--x: no help; give it help= in the parser"). The module docstring says so. This is the stronger form of "`DESCRIBED` empties and its render refuses an entry": with no mapping there is no entry to write, so the page cannot carry a sentence the parser lacks. Reason: 122 made the mapping because a `help=` string was runner code it could not touch that day (122's Decision 3); the stand-in has no other use, and a mapping kept empty would be a parameter nothing passes.
