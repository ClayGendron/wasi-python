# docs/how-to/verify-a-download.md
   15  ## Check an asset's provenance with `gh`
   16  
   17  Every release asset carries *build provenance*: a statement, signed by the release workflow, that names the source and the workflow that built the file. The GitHub CLI, `gh`, checks it. Log `gh` in first, then run this, with `<asset>` the file you downloaded and `<version>` the release's version:
   18  
   19  ```
   20  gh attestation verify <asset> --repo ClayGendron/wasi_python \
   21    --signer-workflow ClayGendron/wasi_python/.github/workflows/release.yml@refs/tags/v<version> \
   22    --source-ref refs/tags/v<version> --deny-self-hosted-runners
   23  ```
   24
