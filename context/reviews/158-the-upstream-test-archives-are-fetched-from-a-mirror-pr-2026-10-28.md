What the code does, READ against Decision 4:

- `get()` (`scripts/00_download.sh:55-90`): with no third field the path is today's, bare `curl` under `set -e`, a mismatch caught by the end-of-script `shasum -c`; with one, `pin_sum` selects the pin by the exact second field and exactly once (an error naming the file otherwise), then `fetch_checked` mirror, then origin. `fetch_checked` (`:37-54`) runs inside `if`, so `set -e` is off within it; every failure is captured (`|| code=$?`, `|| got=unreadable`, `|| { WHY=…; return 1; }`), the `.part` is removed on every miss, and `WHY` is set on every `return 1`, so `$mirror_why` and `$WHY` are never unset under `set -u`.
