## Findings, most severe first

The channel is offered whenever `os.pipe()` succeeds, and nothing falls back when wasmtime cannot open the path. On Linux `/dev/fd` is a link into `/proc`, which a chroot, some build sandboxes and some minimal containers do not mount. Failure: EXECUTED by `probe_no_dev_fd.py`, a channel whose path does not exist → `wasi_python.run(["-c", "print('x')"])` raises `wasmtime._error.WasmtimeError: failed to set stdout file`, a type the runner never promises, before any guest code; descriptors and threads are left as they were.
